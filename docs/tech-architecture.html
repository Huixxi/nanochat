Data Models

Core Entities

-- Users: 核心用户表 CREATE TABLE users ( id UUID PRIMARY KEY, nickname VARCHAR(50) NOT NULL, phone VARCHAR(20) UNIQUE, avatar_config JSONB, -- 头像组件配置 invite_code VARCHAR(8) UNIQUE, -- 该用户的邀请码 invited_by UUID REFERENCES users(id), created_at TIMESTAMP DEFAULT NOW() ); -- Personas: 用户人设数据 CREATE TABLE personas ( user_id UUID PRIMARY KEY REFERENCES users(id), answers JSONB, -- 结构化问答答案 summary TEXT, -- AI 生成的自然语言摘要 tags TEXT[], -- 兼容性标签 embedding VECTOR(768), -- 人设向量（用于匹配） updated_at TIMESTAMP ); -- Conversations: 会话 CREATE TABLE conversations ( id UUID PRIMARY KEY, type VARCHAR(10), -- 'direct' | 'group' | 'ai' ai_persona VARCHAR(50), -- AI 角色标识（如果是 AI 对话） created_at TIMESTAMP DEFAULT NOW() ); -- Messages: 消息 CREATE TABLE messages ( id UUID PRIMARY KEY, conversation_id UUID REFERENCES conversations(id), sender_id UUID, -- NULL 表示系统消息 content TEXT NOT NULL, msg_type VARCHAR(10), -- 'text' | 'image' | 'system' created_at TIMESTAMP DEFAULT NOW() ); -- Invitations: 邀请记录 CREATE TABLE invitations ( code VARCHAR(8) PRIMARY KEY, created_by UUID REFERENCES users(id), used_by UUID REFERENCES users(id), used_at TIMESTAMP, expires_at TIMESTAMP );

Relationship Graph

-- 关系图谱通过 invited_by 字段隐式构建 -- 社交距离通过 BFS 遍历计算： -- 一度 = 直接邀请关系（A invited B 或 B invited A） -- 二度 = 需要经过一个中间人 -- 三度 = 经过两个中间人 -- 为了性能，预计算并缓存社交距离矩阵： CREATE TABLE social_distance ( user_a UUID, user_b UUID, distance SMALLINT, -- 1, 2, 3 path UUID[], -- 中间节点路径 PRIMARY KEY (user_a, user_b) );

Compatibility Engine

# 契合度计算流程 def calculate_compatibility(user_a, user_b): # 1. 向量相似度 (权重 40%) vec_score = cosine_similarity( user_a.persona.embedding, user_b.persona.embedding ) # 2. MBTI 兼容性矩阵 (权重 20%) mbti_score = MBTI_MATRIX[user_a.mbti][user_b.mbti] # 3. 兴趣标签重合度 (权重 25%) tag_score = jaccard_similarity( user_a.persona.tags, user_b.persona.tags ) # 4. 社交风格匹配 (权重 15%) style_score = social_style_match(user_a, user_b) return ( vec_score * 0.4 + mbti_score * 0.2 + tag_score * 0.25 + style_score * 0.15 )

Realtime Communication

WebSocket Architecture

Connection Management

JWT token 认证，每用户一个长连接。Redis pub/sub 支持多实例横向扩展。

Room-based Routing

每个 conversation 是一个 room，消息只广播给 room 内成员。

AI Streaming

AI 回复逐 token 推送，前端实时渲染打字效果。

Presence System

Redis 维护在线状态，心跳检测，30秒超时判定离线。

Message Flow

# 消息处理流程 Client A sends message ↓ WebSocket Server receives ↓ if conversation.type == 'ai': → Enqueue AI generation task → Stream tokens back to Client A elif conversation.type == 'direct': → Persist to DB → Broadcast to room (Client B) → Push notification if B is offline
